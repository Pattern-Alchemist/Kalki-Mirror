## CRITICAL — Pages Show TWO Stacked Footers

The root layout (`src/app/layout.tsx:113`) renders `<SacredFooter />` after **every** page. However, 14 of 18 pages also declare their own inline `<footer>` with a bindu-pulse element. Users see the page's bindu-pulse footer, then immediately below it the full SacredFooter with navigation links.

| SEVERITY | FILE | LINE | ISSUE |
|----------|------|------|-------|
| **HIGH** | `layout.tsx` | 112–113 | Layout wraps children in `<main>` and appends SacredFooter unconditionally |
| **HIGH** | `method/page.tsx` | 486–499 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `practice/page.tsx` | 650–663 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `library/page.tsx` | 676–690 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `research/page.tsx` | 400–410 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `pricing/page.tsx` | 417–430 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `archetypes/page.tsx` | 348–358 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `consultations/page.tsx` | 394–404 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `codex/page.tsx` | 404–425 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `aghoiri-tantra/page.tsx` | 564–577 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `archive/page.tsx` | 605–615 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `patterns/page.tsx` | 607–617 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `practice/japa/page.tsx` | 353–362 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `practice/timer/page.tsx` | 371–380 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |
| **HIGH** | `redeem/page.tsx` | 418–427 | Inline bindu-pulse footer + layout SacredFooter = **2 footers** |

**Only `page.tsx` (homepage) avoids this** — it has no inline footer and relies solely on the layout SacredFooter.

**Recommendation:** Either (a) remove SacredFooter from layout.tsx and add it to each page explicitly, or (b) remove all inline `<footer>` elements from individual pages and let SacredFooter serve as the sole site-wide footer. The bindu-pulse element could become a section divider above the SacredFooter rather than a separate footer.

## CRITICAL — Nested `<main>` Tags (Invalid HTML)

The layout wraps children in `<main className="pt-16 md:pt-20">` (layout.tsx:112). 12 pages also declare their own `<main>`, producing nested `<main>` elements — invalid HTML that causes screen readers to announce the main landmark twice.

### Top 3 Fixes (Highest Impact)

1. **Eliminate double footer** — Remove inline `<footer>` from all 14 pages, OR remove SacredFooter from layout.tsx. This is the most visible issue.

2. **Fix nested `<main>`** — Change layout.tsx line 112 from `<main>` to `<div>`, OR change all 11 page-level `<main>` to `<div>`. This fixes HTML validity and screen reader behavior.

3. **Standardize hero heights** — Adopt 2–3 approved heights and apply consistently. Pay special attention to `pricing` (70vh) and `consultations` (75vh) which are noticeably shorter than other pages.
