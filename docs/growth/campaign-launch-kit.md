# Campaign Launch Kit — First Real Traffic Push

> Every link below is pre-tagged for the attribution layer. A seeker who clicks,
> walks the wizard and hits submit lands in **Admin → Consultation Pipeline**
> with a source chip — you will know exactly which channel produced the lead.
> Test ritual: click any link → submit a wizard intake → the chip appears in the
> pipeline → remove it with the card's **Delete lead permanently** button.

**Naming convention (never deviate):** all lowercase, hyphens, no spaces.

| Param | Rule | Examples |
|---|---|---|
| `utm_source` | the platform | `instagram` `youtube` `whatsapp` `facebook` `x` `pinterest` `linkedin` `email` `reddit` `quora` |
| `utm_medium` | the placement | `bio` `story` `post` `description` `comment` `status` `broadcast` `pin` `answer` `signature` |
| `utm_campaign` | `<theme>-<mon><yy>` | `aug26-launch` `navratri-oct26` `guhya-halloween-oct26` `shivaratri-mar27` |

## How a lead reads in the pipeline

- Card chip: `instagram · aug26-launch` (source · campaign)
- Drawer → Attribution: first touch (where they landed) vs last touch (what
  finally converted), sessions before submitting, click-ids (`gclid`/`fbclid`)
  when you later run paid.
- Booking rate and per-status counts roll up automatically.

## Notes

- Tagged URLs do **not** harm SEO — canonical tags fold them back to the clean
  URL; Google consolidates. Tag freely.
- Paid ads later: keep the same convention, add `utm_medium=cpc` and the
  click-id params arrive automatically (`gclid` etc.) — attribution already
  stores them.
- Never tag internal links between your own pages — that would pollute
  last-touch data. Only tag links that leave your channels.
